# Contribuindo

Catoons TD é atualmente um projeto pessoal de portfólio, mas relatórios de bugs e sugestões são bem-vindos.

## Reportando bugs

Antes de abrir uma Issue:

1. confirme que o problema ocorre na versão mais recente;
2. anote mapa, dificuldade, wave e herói;
3. pressione `F8` e registre o FPS/quantidade de entidades se o problema for de performance;
4. se possível, descreva passos reproduzíveis.

Use o template **Bug report** do GitHub.

## Sugestões

Use o template **Feature request**. Explique o problema que a ideia resolve antes de detalhar a solução desejada.

## Pull Requests

Como o projeto está em fase de beta e balanceamento, alterações grandes devem ser discutidas em uma Issue antes de um PR. Prefira mudanças pequenas e testáveis.

## Padrão de commits sugerido

```text
feat: adiciona ...
fix: corrige ...
balance: ajusta ...
perf: otimiza ...
docs: documenta ...
chore: manutenção ...
```
