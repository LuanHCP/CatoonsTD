# Checklist para publicar o projeto no portfólio

- [ ] Criar repositório público `CatoonsTD`.
- [ ] Subir esta pasta para a branch `main`.
- [ ] Ativar GitHub Pages.
- [ ] Adicionar a URL do Pages no campo Website do repositório.
- [ ] Capturar 4–6 screenshots sem painel de debug.
- [ ] Adicionar uma imagem de capa ao README.
- [ ] Criar tag `v0.9.0-beta`.
- [ ] Criar GitHub Release e anexar o ZIP Windows.
- [ ] Testar o link do Pages em outro navegador/computador.
- [ ] Abrir uma Issue de teste para validar os templates.
- [ ] Adicionar o projeto ao LinkedIn.
- [ ] Adicionar uma linha curta no currículo.
